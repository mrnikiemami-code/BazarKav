## گارد خودکار فعلی

اجرای محلی و CI:

```bash
python3 tools/architecture/check_architecture.py
```

این ابزار فقط بررسی ساختاری است: محل پروژه و فایل، ارجاع مجاز، وابستگی دوری، منع package و project reference در Domain/Contracts و تفکیک فایل‌های Command، Query و Validator.
گارد Request علاوه بر نام فایل، declaration نوع را نیز بررسی می‌کند؛ فایل تجمیعی مانند TenantRequests.cs نمی‌تواند محل نادرست را پنهان کند. پسوند Request برای DTO ورودی HTTP رزرو است. تست معماری Tenant، RequestType واقعی metadata endpoint را هم بررسی می‌کند.
ProjectReference مشترک در فایل props/targets فعلاً ممنوع است تا ارجاع پنهان ایجاد نشود.
کد مشترک تولید باید داخل BuildingBlocks باشد؛ C# خارج از ریشه‌های تعیین‌شده مجاز نیست.

معنای کد، امنیت، schema و behavior runtime با این ابزار اثبات نمی‌شود. اکنون ArchitectureTests برای وابستگی assemblyهای BuildingBlocks و integration tests برای خطا، correlation، trace و لاگ موجودند. تست isolation، آداپتر خواندنی و کیفیت داده هنگام ایجاد ماژول‌های مربوط اضافه می‌شوند.

## گیت تحویل

1. اجرای گارد ساختاری و بررسی diff.
2. پس از وجود پروژه، build و تست ضروری مرتبط با همان تغییر.
3. کنترل دستی گاردهایی که هنوز خودکار نشده‌اند.
4. ثبت وضعیت واقعی، موارد باز و شواهد بررسی.
5. توقف پس از کار درخواستی؛ شروع تسک پیاده‌سازی بعدی بدون درخواست کاربر ممنوع.

افزودن لایه، استثنای وابستگی یا تغییر فولدربندی باید ابتدا در سند معماری با دلیل ثبت شود و سپس گارد متناظر اصلاح شود. عبور CI به‌تنهایی به معنی تأیید کامل معماری نیست.
